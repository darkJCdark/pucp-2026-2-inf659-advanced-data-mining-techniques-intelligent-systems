How to use
  1. Load a word preset or add your own words with 2D coordinates
  2. Use the Step Guide (right panel) to walk through each stage
  3. Modify Q, K, V matrix values with sliders and see instant updates
  4. Click a heatmap cell (e.g. q_cat → k_dog) to focus that pair — all other words dim across every plot
  5. Click the same cell again, or click anywhere on the Q/K plot, to clear the focus
  6. Switch heatmap views: Raw Scores → Cosine Similarity → Attention Weights
  7. Adjust Temperature τ to see sharp vs. uniform softmax

Query (Q)

What this word is searching for. Q rotates/scales the embedding to define a search direction.

Key (K)

What this word broadcasts. If a key aligns with a query, that word receives high attention.

Value (V)

What each word contributes when attended to. Independent of Q/K — only changes the output position.

Temperature τ

Low τ → sharp, winner-take-all attention. High τ → soft, uniform attention across all words.

① Value vectors — dot size ∝ α weight — ★ = output
